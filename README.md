## Descripción del Proyecto
Aplicación web funcional para la administración, control y filtrado de equipos y componentes de laboratorio informático, conectada a una base de datos en la nube mediante Supabase (PostgreSQL).

## Plataforma Seleccionada
* **Base de Datos:** Supabase (SQL / PostgreSQL)
* **Frontend:** HTML5, CSS3 y JavaScript (Vanilla)

## Funcionalidades Implementadas
- [x] Alta/Crear componentes informáticos.
- [x] Listado y consulta en tiempo real.
- [x] Modificación y actualización de registros.
- [x] Baja/Eliminación con confirmación previa.
- [x] Búsqueda por texto y filtrado por categoría y estado.
- [x] Persistencia de datos en la nube.
